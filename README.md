# HR Analytics Dashboard

## Project Overview
The HR Analytics Dashboard is an interactive Power BI project designed to analyze employee data and uncover meaningful workforce trends. It transforms raw HR data into clear visual insights, helping stakeholders understand attrition patterns, department distribution, and employee demographics through an easy-to-navigate dashboard.

## Objectives
- Analyze employee attrition trends across departments, job roles, and demographics
- Provide a clear, visual summary of key HR metrics
- Enable interactive data exploration through filters and slicers
- Support data-driven decision-making in HR management

## Tools & Technologies
- **Microsoft Power BI** – Dashboard design and visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – Calculated measures and KPIs

## Key Features
- Employee headcount analysis
- Department-wise employee analysis
- Attrition analysis
- Gender-wise analysis
- Job role analysis
- Employee performance analysis
- Interactive filters and slicers
- KPI cards and charts
- Data-driven HR insights

## Dashboard Insights
The dashboard presents workforce data through multiple visual perspectives, including:
- Overall employee count and attrition rate
- Attrition breakdown by education, salary slab, gender, and age group
- Department-wise employee distribution
- Job role-wise attrition and performance patterns
- Trend of attrition based on years spent at the company

These visuals help identify which employee segments show higher attrition and support deeper analysis of workforce composition.

## How to Use
1. Clone or download this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Use the slicers and filters (e.g., Department, Age Group) to explore the data interactively.
4. Hover over charts and visuals to view detailed tooltips and values.
